A front-end clone of Divar built with Vanilla JavaScript.
This project is a marketplace platform where users can browse advertisements, filter posts, manage their profile, and interact with different sections similar to the original Divar website.

## 🚀 Demo

Live Demo: [Add your deployed link here]

## 📌 Features

* User authentication with token management
* User profile panel
* View user's advertisements
* Pagination for user posts
* City selection and management
* Save selected cities using cookies
* Recently viewed posts using localStorage
* Post filtering and searching
* Category browsing
* Responsive design
* SweetAlert confirmation dialogs
* Dynamic rendering of posts from API

## 🛠 Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* Bootstrap
* Git & GitHub
* REST API
